# Lists 

Follow these guidelines to document lists correctly: 

- **Alphabetical order**: Make sure that bullet lists are ordered alphabetically unless they have a hierarchical order that does not involve sequence.

    ??? example

        This list has a hierarchical order but does not determine any sequence:

        *The catholic church consists of:*

        - *The pope*
        - *Cardinals*
        - *Archbishops*
        - *Bishops*
        - *Priests*
        - *Deacons*


- **Bullet lists**: Use bullet lists when the items are not ordered by sequence.

    ??? example

        Before using the application, make sure you have the following software installed:
        
        - Python
        - Git
        - Docker

- **Leading lines**: Always include a line of text before lists explaining its content. Avoid starting this line with *"There are"*.

    ??? example

        Here you can find our SDK in different programming languages:

        - C#
        - Java
        - Ruby
        

- **Numbered lists**: Use numbered lists when the items are ordered. When documenting a step-by-step process, avoid starting steps with expressions like *"first"*, *"then"*, or *"finally"*

    ??? example

        Follow these steps to save your file:

        1. Click **File** on the main menu.
        2. Select **Save File**.
        3. Enter the following information:

            - **Filename**: File name. The extension is optional.
            - **Path**: Directory where the file will be saved. Click the folder to select the path using the explorer.
        
        4. Click **Save**.

- **Parallel lists**: Make sure the lists are uniform, meaning that their items are all sentences, commands, or statements. 

    ??? example

        The system consists of the following modules:

        - **Billing module**: Allows issuing bills to clients.
        - **Client module**: Allows adding, editing, and deleting clients.
        - **Product module**: Allows adding, editing, and deleting products.

- **Punctuation and format**: If the list contains a term and its definition separated by a colon (:), the term must use bold format and sentence capitalization (Except for capitalized words and acronyms like RestFUL or HTTP.) And the definition must start with a capital letter. All list items must end with period except if the list contains one-word items only.
